# AWS S3 Static Website

## Overview
This project is a modern, tech‑styled static website hosted using Amazon S3. It demonstrates AWS cloud fundamentals including S3 bucket configuration, static website hosting, public access policies, and lightweight front‑end deployment.

## Live Website
http://svaughn26-s3-site.s3-website.us-east-2.amazonaws.com

## Technologies Used
- AWS S3 (Static Website Hosting)
- HTML5
- CSS3 (modern gradients, animations, glass‑card UI)
- Google Fonts (Inter)

## Features
- Ultra‑modern green tech theme
- Animated neon border
- Glass‑card blur effect
- Responsive centered layout
- Fully hosted on AWS S3 (free tier)

## What I Learned
- How to configure S3 buckets for public hosting
- How to enable static website hosting
- How to apply bucket policies for public access
- How to deploy front‑end content to AWS
- How to host a website without servers or EC2
